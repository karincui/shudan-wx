# 书单小程序（云开发）

AppID：`wx90bac43ea58dbd99`  
目录：`H:\xiaoshuo-wxapp`

个人小说 / 网文书单工具：记录、筛选、排序、置顶、随机抽书，支持多种导入与备份导出；可切换白天 / 黑夜或自定义背景色、字体色、背景图。  
数据保存在 **微信云开发**（云数据库 + 云存储），同一微信换手机可同步。


更完整的产品说明见：[需求文档.md](./需求文档.md)

---

## 第一次开通（必做）

1. 用微信开发者工具打开本项目  
2. 顶部点 **「云开发」** → 开通（按提示创建环境）  
3. 在云开发控制台复制 **环境 ID**  
4. 打开 `miniprogram/cloudEnv.js`（或确认 `app.js` 内）环境 ID 已填写，例如：

```js
module.exports = {
  envId: 'xiaoshuo-d1gjmmum1bef3c60d',
}
```

5. 云开发控制台 → **数据库** → 新建集合：
   - `novels`（书单）
   - `prefs`（标签偏好 + 主题）
6. 两个集合权限设为：**仅创建者可读写**  
7. **云存储** 保持默认开通（附件、主题背景图会传到这里）  
8. 重新编译小程序

## 本地旧数据

若之前在模拟器里用过本地存储，**云端为空时会自动把本地书单迁到云上一次**。  
旧附件若只存在本地路径，迁云后附件字段可能清空，书目还在；可重新上传附件。

## 云函数（截图 / Excel 必传）

开发者工具里对以下目录分别 **右键 → 上传并部署：云端安装依赖**：

- `cloudfunctions/ocrPrinted`（截图文字识别）
- `cloudfunctions/parseTableFile`（Excel `.xlsx` 解析）

CSV / TXT / 剪贴板表格、md 备份、主题色、排序不依赖这两个云函数。  
主题背景图走云存储上传，不需要额外云函数。

默认排序依赖 `listScore` 索引；若控制台提示缺索引，按提示补建即可。

## 个性化说明（简）

「我的」→ **个性化外观**：

1. 选 **白天** / **黑夜** / **自定义**  
2. 自定义下可改背景色、字体色  
3. **选择并裁剪**：相册选图 → 系统裁剪 → **保存并应用**  
4. 主题存本地，并同步到云端 `prefs.theme`
